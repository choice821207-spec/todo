# 할 일 목록 (TODO)

설치나 빌드 없이 브라우저에서 바로 동작하는 할 일 관리 앱입니다. 순수 HTML, CSS, JavaScript로만 만들었습니다.

## 데모

- GitHub Pages: https://choice821207-spec.github.io/todo/
- Vercel: https://todo-six-gamma-29.vercel.app

## 기능

- **추가**: 할 일을 입력하고 Enter 또는 `추가` 버튼
- **완료 표시**: 체크박스로 완료/미완료 전환
- **수정**: 항목을 더블클릭하거나 `수정` 버튼 (Enter 또는 `저장` 버튼으로 저장, Esc로 취소, 내용을 비우고 저장하면 삭제)
- **전체 완료**: `모두 완료` / `모두 해제`로 모든 항목을 한꺼번에 전환
- **삭제**: 항목별 `삭제` 버튼, 또는 `완료 항목 삭제`로 한꺼번에 삭제
- **실행 취소**: 삭제 직후 나타나는 `실행 취소` 버튼이나 Ctrl+Z로 마지막 삭제를 되돌립니다 (새로고침하면 되돌릴 수 없습니다)
- **순서 변경**: 항목의 `↑` `↓` 버튼으로 한 칸씩 이동
- **필터**: 전체 / 진행 중 / 완료 (선택한 필터는 새로고침해도 유지됩니다)
- **백업**: `내보내기`로 목록을 JSON 파일로 저장하고, `가져오기`로 파일에 있는 항목 중 현재 목록에 없는 것만 추가합니다
- **자동 저장**: 브라우저 `localStorage`에 저장되어 새로고침해도 목록이 유지됩니다. 저장에 실패하면 화면에 안내가 표시됩니다
- **탭 동기화**: 같은 브라우저의 다른 탭에서 바꾼 내용이 바로 반영됩니다
- **다크 모드**: 시스템 설정을 따릅니다

## 실행 방법

`index.html`을 브라우저에서 열면 됩니다.

로컬 서버로 실행하려면 프로젝트 폴더에서 다음 명령을 실행한 뒤 http://127.0.0.1:8080 에 접속합니다.

```bash
npx http-server
```

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 스타일 (라이트/다크 테마) |
| `favicon.svg` | 브라우저 탭 아이콘 |
| `app.js` | 할 일 추가·수정·삭제·순서 변경·필터·저장·백업 로직 |

## 개발

앱을 쓰는 데는 설치가 필요 없습니다. 테스트와 코드 검사를 돌릴 때만 Node.js로 개발 도구를 설치합니다.

```bash
npm install
npm test              # test/app.test.js — 실제 화면을 jsdom에 올려 동작 확인
npm run lint          # ESLint
npm run format        # Prettier로 app.js, style.css, 테스트 코드 정리
npm run format:check  # 정리가 필요한 파일이 있는지만 확인
```

## 데이터 저장

할 일 목록은 서버로 전송되지 않고 사용 중인 브라우저의 `localStorage`(`todos` 키)에만 저장됩니다. 주소(출처)마다 저장소가 분리되므로 로컬, GitHub Pages, Vercel의 목록은 서로 공유되지 않으며, 다른 브라우저나 기기에서도 보이지 않습니다. 목록을 옮기려면 `내보내기`로 받은 파일을 옮길 곳에서 `가져오기`로 불러옵니다. 선택한 필터는 `todos-filter` 키에 저장됩니다.

## 배포

`master` 브랜치에 `git push` 하면 두 곳 모두 자동으로 다시 배포됩니다.

- **GitHub Pages**: `master` 브랜치의 루트에서 배포합니다.
- **Vercel**: 프로젝트가 이 GitHub 리포지터리와 연결되어 있으며, `master`가 프로덕션 브랜치입니다.
