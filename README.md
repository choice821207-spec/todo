# 할 일 목록 (TODO)

설치나 빌드 없이 브라우저에서 바로 동작하는 할 일 관리 앱입니다. 순수 HTML, CSS, JavaScript로만 만들었습니다.

## 데모

- GitHub Pages: https://choice821207-spec.github.io/todo/
- Vercel: https://todo-six-gamma-29.vercel.app

## 기능

- **추가**: 할 일을 입력하고 Enter 또는 `추가` 버튼
- **완료 표시**: 체크박스로 완료/미완료 전환
- **수정**: 항목을 더블클릭하거나 `수정` 버튼 (Enter로 저장, Esc로 취소, 내용을 비우고 저장하면 삭제)
- **삭제**: 항목별 `삭제` 버튼, 또는 `완료 항목 삭제`로 한꺼번에 삭제
- **필터**: 전체 / 진행 중 / 완료
- **자동 저장**: 브라우저 `localStorage`에 저장되어 새로고침해도 목록이 유지됩니다
- **다크 모드**: 시스템 설정을 따릅니다

## 실행 방법

`index.html`을 브라우저에서 열면 됩니다.

로컬 서버로 실행하려면 프로젝트 폴더에서 다음 명령을 실행한 뒤 http://127.0.0.1:8080 에 접속합니다.

```bash
npx http-server
```

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 스타일 (라이트/다크 테마) |
| `app.js` | 할 일 추가·수정·삭제·필터·저장 로직 |

## 데이터 저장

할 일 목록은 서버로 전송되지 않고 사용 중인 브라우저의 `localStorage`(`todos` 키)에만 저장됩니다. 주소(출처)마다 저장소가 분리되므로 로컬, GitHub Pages, Vercel의 목록은 서로 공유되지 않으며, 다른 브라우저나 기기에서도 보이지 않습니다.

## 배포

`master` 브랜치에 `git push` 하면 두 곳 모두 자동으로 다시 배포됩니다.

- **GitHub Pages**: `master` 브랜치의 루트에서 배포합니다.
- **Vercel**: 프로젝트가 이 GitHub 리포지터리와 연결되어 있으며, `master`가 프로덕션 브랜치입니다.
